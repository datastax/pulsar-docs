= Installation topologies
:navtitle: Cluster Sizing Reference

This page describes recommended starting points for {pulsar-short} deployments.

* SANDBOX (or {pulsar-short} Standalone) is an all-in-one single-node deployment that is useful for taking {pulsar-short} for a test drive.
* DEVELOPMENT is a 3-node deployment that is not highly available, but able to maintain parity with the TESTING environment.
* SINGLE REGION TESTING ENVIRONMENT is a highly-available 3/3/3 deployment.
* HIGH-AVAILABILITY PRODUCTION ENVIRONMENT is a highly-available deployment replicated across 3 zones in 1 region.

== Minimum sizing

The number of nodes in a highly available cluster depends on the number of zones in the region.
{company} recommends aligning the replication factor with the AZ count.
For example, if there are 3 zones, then set a replication factor of 3.

== Hardware sizing

The following table lists the minimum hardware requirements for a {pulsar-short} cluster.

[cols=4*]
|===
|Environment |Server Component |Hardware Spec |Note

|DEVELOPMENT
|{zookeeper-short}, broker, and {bookkeeper-short}
a|* CPU: 8 vCPU
* Memory: 16 GB
* Data Disk: 64 GB SSD
a|Data disks are shared by {zookeeper-short} data, {bookkeeper-short} journal, and {bookkeeper-short} ledger

|TEST
|{zookeeper-short}
a|* CPU: 2 vCPU
* Memory: 4 GB
* Data Disk: 32 GB SSD
|

|TEST
|Broker and function worker
a|* CPU: 8 vCPU
* Memory: 16 GB
|No data disk

|TEST
|Bookie
a|* CPU: 4 vCPU
* Memory: 16 GB
* Data Disk Journal: 32 GB SSD
* Data Disk Ledger: 256 GB SSD
|

|TEST
|{pulsar-short} proxy, function worker
a|* CPU: 4 vCPU
* Memory: 8 GB
|

|PRODUCTION
|{zookeeper-short}
a|* CPU: 4 vCPU
* Memory: 4 GB
* Data Disk: 64 GB SSD
|

|PRODUCTION
|Broker
a|* CPU: 8 vCPU
* Memory: 16 GB
* No data disk
|

|PRODUCTION
|Bookie
a|* CPU: 8 vCPU
* Memory: 32 GB

* Data Disk Ledger: 1024 GB SSD
|Ledger disk capacity can be beyond 1TB.

|PRODUCTION
|{pulsar-short} proxy, AutoRecovery
a|* CPU: 4 vCPU

|

|PRODUCTION
|Function worker (dedicated)
a|* CPU: 4 vCPU
* Memory: 8 GB
|
|===
